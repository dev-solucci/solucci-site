# Site da Solucci

Site institucional em HTML, CSS e JavaScript, com Design, Dev e Games. Publicação pelo repositório conectado à Hostinger, conforme DEPLOY.md.

A abertura usa o símbolo da marca em WebGL, com imagem estática de reserva. A fábrica utiliza animação 3D em vídeo. O movimento respeita a preferência do sistema e pode ser pausado pelo visitante. Fontes, imagens e malha são servidas localmente.

## Arquivos ativos

index.html: conteúdo, metadados, dados estruturados e Analytics.
css/site.css: composição e responsividade.
js/site.js: navegação e controle de movimento.
js/scene.js: renderização do símbolo.
assets: fontes, imagens, vídeo e malha.
marca: manual existente, preservado nesta publicação.
